📐 ฉบับย่อ vs popup เดิม
popup เดิม = modal เต็มจอใหญ่ (max-w-md + confetti + ปุ่มปิด) — ฉบับย่อ = การ์ดเล็ก ~310px มุมขวาล่าง ไม่บังเนื้อหา เล่นหลายผลต่อเนื่องได้
🎯 เนื้อหาที่ย่อมา
ธง + ชื่อประเภท + เวลาออก → เลขรางวัลหลัก (lotto balls / ชิปราศี) → รางวัลรอง 2-3 ชิ้น → footer: ปุ่มผลถัดไป + จำนวนคิว + ตัวนับถอยหลังปิด
⚙️ พฤติกรรม
เด้งเมื่อผลใหม่ publish (SSE 'results' เหมือนเดิม) • auto-hide ~8-10 วิ • กด ✕ หรือ คลิกนอกปิดได้ • queue สูงสุด 3-4 ผล เรียงตามเวลา • เคารพ prefers-reduced-motion
